# ThreeShirt

ThreeShirt é um sistema web em desenvolvimento para apoiar os alunos na escolha da camiseta do terceiro ano do Ensino Médio.

A proposta é organizar o processo de apresentação de propostas, coleta de preferências e votação, tornando a participação dos estudantes mais estruturada e transparente.

## Objetivos

- Permitir que os alunos registrem suas preferências.
- Organizar propostas de camisetas.
- Disponibilizar um processo de votação controlado por administradores.
- Apresentar os resultados de forma clara.

## Status

O projeto está em fase de desenvolvimento. Funcionalidades e decisões técnicas podem ser ajustadas durante a implementação.

## Tecnologias

- Python
- Django
- SQLite
- HTML, CSS e JavaScript

## Público-alvo

Alunos do Ensino Médio envolvidos no processo de escolha da camiseta do terceiro ano.
